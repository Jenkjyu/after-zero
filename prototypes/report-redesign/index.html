After Zero 统计页 · 三套静态原型

三套用的是同一份数据——12 笔债务喂给真实的 www/js/calc.js 算出来的结果 （余额量级与类型占比跟真机截图逐项对齐），所以三栏之间的差异只来自设计本身。 没有改动任何业务代码，正式页面不受影响。

方案 A原生延续
石墨 hero + 色雾、18px 圆角、--e2 阴影、2×2 KPI、5 张同构图表卡。 修掉审计点名的三处不一致：图例改胶囊、⋮ 换具名按钮、补回色雾层。

方案 B债务洞察叙事
没有 hero 卡，总额写进句子。分成"发现 / 风险 / 过程 / 压力 / 结构"五段， 图表退成结论的证据。结论规则驱动；走势图可拖动读数、压力图可切面积/柱状、占比是可旋转饼图。

方案 C极简数据产品
零卡片容器，只有留白和发丝线。段间距 34px，图表尺寸砍半， 全页只有墨色 + 琥珀两个数据色，数字比图大。

三套的结构性差异（不是配色差异）

A 原生延续B 债务洞察叙事C 极简数据产品
顶部石墨渐变 hero + 色雾动效 + 归零进度条，36px 大数字报告头：日期 + 判断句标题，总额写在段落里无卡片，46px 巨号数字直接压在页面底色上
容器5 张同构卡片（18px / --card-grad / --e2 / 顶部内高光）五个语义段落，只有图表处有轻容器（--e1）零容器，只有 hairline + 34px 段间距
压力图4 格摘要 + 全 27 个月柱状图 + 点击展开当月明细面积 / 柱状两种模式可切换（默认面积），横向滑动 + 点月看明细、再点收起柱高砍到 78px，只留 2 条刻度线，选中月的数字在图上方
走势图折线 + 面积渐变 + 3 个时间刻度三个节点的名称+时间+金额标在图上，按住拖动可读任意时间点余额，不画坐标轴sparkline 级细线，只标首尾两个数字
排行全部 12 笔 + 余额/利率/剩余利息三档切换按累计占比 70% 截断（当前 4 笔），其余折叠全部 12 笔，无底槽实心条，高息用琥珀色区分
类型占比26px 堆叠条 + 胶囊图例（名称/百分比/金额）可拖拽旋转的甜甜圈，标签贴边缘 + 折线引线，文字始终水平，无图例4px 细线 + 三行文字
总结6 行 key-value，卡片内规则驱动：4 条候选按严重度排序取前 3 + "最该先动手"展开定义列表，高息相关行用琥珀色
数据色3 色角色制：蓝=量级 / 琥珀=成本 / 绿=进度风险二档：红=年化≥18% / 蓝=其余，加本金蓝·利息琥珀2 色：墨色 + 琥珀

三套都保留了：本金/利息可区分（颜色 + 常驻图例 + 文字读数三重编码）、每个数值都有不靠手势就能读到的路径、 "预测不是承诺 / 本 App 不保存历史余额"的说明、走势图 X 轴按真实时间比例而非数组下标等距。 图表卡片一律不透明背景，没有用毛玻璃。
所有配色都跑过 dataviz skill 的 validate_palette.js（浅深两套各验一次）， 过程和数值记在 README.md 里——包括一处刻意偏离验证器的判断（方案 C 的墨色），以及 验证过程中发现的两个正式 App 现存的配色问题。
